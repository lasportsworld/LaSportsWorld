You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

## Google Reviews

The homepage can show live Google Maps rating and review data through the Google Places API. Configure these server-only environment variables in the deployment environment:

```bash
GOOGLE_PLACES_API_KEY="your Google Maps Platform API key"
GOOGLE_PLACE_ID="your Google Maps place ID"
GOOGLE_REVIEWS_REFRESH_SECONDS="21600"
```

`GOOGLE_REVIEWS_REFRESH_SECONDS` is optional and defaults to 6 hours. Values below 300 seconds are ignored to avoid excessive Places API calls.
